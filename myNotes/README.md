# Мои заметки
# Работа с текстом в редакторах: основные горячие клавиши

## Навигация и перемещение каретки

* `Home` / `End` (на Mac: `Cmd + ←` / `Cmd + →`) — быстрый переход в начало или конец текущей строки.
* `Page Up` / `Page Down` (на Mac: `Fn + ↑` / `Fn + ↓`) — скролл документа на один экран вверх или вниз.
* `Ctrl + Home` / `Ctrl + End` (на Mac: `Cmd + ↑` / `Cmd + ↓`) — мгновенный прыжок в самый старт или финал файла.
* `Ctrl + ←` / `Ctrl + →` (на Mac: `Option + ←` / `Option + →`) — шаг курсора по целым словам.

## Выделение фрагментов

* `Ctrl + A` (на Mac: `Cmd + A`) — выбрать всё содержимое документа разом.
* `Shift + ←` / `Shift + →` — посимвольный захват текста.
* `Ctrl + Shift + ←` / `Ctrl + Shift + →` (на Mac: `Option + Shift + ←` / `Option + Shift + →`) — выделение текста блоками по словам.
* `Shift + ↑` / `Shift + ↓` — выделение строк вверх или вниз от позиции курсора.
* `Cmd + Shift + ←` / `Cmd + Shift + →` (только Mac) — быстро выделить всю строку до начала или конца.

## История правок и сохранение

* `Ctrl + S` (на Mac: `Cmd + S`) — сохранить текущие изменения в файл.
* `Ctrl + Z` (на Mac: `Cmd + Z`) — отменить последнее действие.
* `Ctrl + Y` или `Ctrl + Shift + Z` (на Mac: `Cmd + Shift + Z`) — повторить отменённую правку.

## Форматирование отступов

* `Tab` — добавление отступа (обычно шаг в 2–4 пробела в зависимости от настроек редактора).
* `Shift + Tab` — уменьшение уровня отступа текущей строки или целого выделенного блока.
